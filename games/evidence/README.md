# 参赛证据清单

该目录用于保存正式方案中每个关键结论的可复核依据。最终 PDF 中引用的数字应能追溯到这里或项目数据库。

## 建议子目录

```text
evidence/
  system/       前后端截图、接口响应、部署信息
  data/         数据规模、类别分布、抽样清单
  metrics/      性能、质量、人工效率和投入产出统计
  bilingual/    中英术语表、双语输出和审校记录
  cases/        端到端典型案例
```

## 当前可用证据

- 真实 DJI 铁路巡检视频 24 段。
- 已抽取并入库 1716 帧图像描述。
- 视频级语义名称、帧级描述和关键词已可在前端浏览。
- FastAPI、Vue、PostgreSQL 和本地 DeepSeek-VL2 构成可运行链路。
